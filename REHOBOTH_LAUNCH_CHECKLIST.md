# REHOBOTH ETHIOPIAN COFFEE

## Launch Checklist

## Content and Assets

- Replace all Unsplash placeholder images with production photography.
- Upload homepage hero desktop and mobile videos.
- Upload poster images for every video.
- Add founder portrait and founder story content.
- Add real coffee product names, descriptions, pricing, origin, roast, process, and tasting notes.
- Add real market product categories and descriptions.
- Add ceremony content and inquiry CTA.
- Add at least 3 testimonials.
- Add real address, phone, hours, parking, and directions URL.
- Confirm image alt text in CMS.
- Compress images and videos before upload.

## SEO

- Confirm `NEXT_PUBLIC_SITE_URL`.
- Confirm page titles and meta descriptions.
- Submit `/sitemap.xml`.
- Confirm `/robots.txt`.
- Add LocalBusiness/Cafe schema with real NAP.
- Add Product schema once Shopify products are live.
- Add Event schema for real events.
- Add Open Graph images.
- Add canonical URLs.
- Create local landing pages if launch scope includes them.

## Analytics

- Add `NEXT_PUBLIC_GA4_ID`.
- Verify GA4 page views.
- Track direction clicks.
- Track call clicks.
- Track coffee CTA clicks.
- Track ceremony CTA clicks.
- Track newsletter/testimonial form submissions when added.
- Confirm consent/privacy requirements.

## Google Search Console

- Verify domain property.
- Submit sitemap.
- Inspect homepage.
- Inspect `/coffee`, `/market`, `/about`, `/visit`.
- Monitor indexing after launch.

## Google Business Profile

- Confirm business name.
- Confirm category and secondary categories.
- Confirm address, phone, website, and hours.
- Upload 20+ launch photos.
- Add coffee products/services.
- Add ceremony/private events if available.
- Add review link to Visit page and QR cards.

## Social Links

- Confirm Instagram URL.
- Confirm Facebook/TikTok if active.
- Add social links to footer.
- Prepare launch post and first 2 weeks of content.

## Performance Testing

- Run `npm run build`.
- Run Lighthouse on desktop and mobile.
- Check LCP on homepage hero.
- Check CLS with loaded media.
- Confirm images use responsive dimensions.
- Confirm videos are compressed and lazy/controlled where appropriate.

## Accessibility Testing

- Keyboard navigation.
- Focus states.
- Color contrast.
- Alt text.
- Reduced motion.
- Touch target sizes.
- Form labels/errors when forms are added.
- Video pause/fallback strategy.

## Asset Optimization

- AVIF/WebP for images.
- MP4/WebM for video.
- Poster images for video.
- Mobile-specific crops.
- Avoid uploading RAW/high-res originals to CMS.
- Check file sizes against asset map.

## Backup Strategy

- Keep RAW photo/video files on external or cloud archive.
- Keep edited masters separate from web exports.
- Export Sanity dataset before launch.
- Export Shopify products before launch.
- Keep `.env` values in password manager/Vercel, not git.
- Confirm git remote backup.

## Deployment

- Configure Vercel environment variables.
- Connect production domain.
- Confirm Cloudflare DNS/CDN settings.
- Confirm HTTPS.
- Confirm redirects.
- Confirm 404 page.
- Smoke test production pages.

---

## Post-Launch Checklist

### First 24 Hours

- Confirm homepage loads on mobile and desktop.
- Confirm `/coffee`, `/market`, `/about`, `/visit`.
- Confirm sitemap is accessible.
- Confirm GA4 real-time page views.
- Confirm Google Search Console can inspect pages.
- Confirm Google Business Profile website link.
- Check Vercel logs.
- Check contact/call/directions links.
- Check social links.

### First Week

- Monitor Search Console indexing.
- Monitor GA4 traffic and top pages.
- Review Core Web Vitals signals.
- Add first Google Business Profile post.
- Upload more Google Business Profile photos.
- Ask first 10 happy customers for reviews.
- Publish 2 reels and 3 feed posts.
- Collect first testimonials.
- Fix any content gaps found by staff/customers.

### First Month

- Review search queries.
- Optimize Visit page based on local search behavior.
- Add real event pages.
- Add coffee education guide.
- Add ceremony/private events page if not already live.
- Review product conversion once Shopify is connected.
- Refresh homepage hero if seasonal content changes.
- Archive all launch assets and document filenames.
